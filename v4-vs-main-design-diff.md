# v4.0 vs main — Design Diff Reference

## Context

This document is a precise, engineering-grade delta between the **live portfolio** (`main` / v3.5, served at https://thomasjbutler.github.io/) and the **v4.0 redesign target** captured in `design_handoff_matrix_portfolio/` on the `v4.0-ShadCNRedesign` branch. It describes the "main → now" change set — what each surface looks like today versus what v4.0 specifies — so the build can be planned against exact source references. It complements (and does not duplicate) the separate version-timetravel history site, which records the project's evolution over time; this file is concerned only with the current main-to-target gap.

Throughout: "live (v3.5)" = the shipped React 19 SPA on `main`; "v4.0 target" = the handoff artboards (`canvas/sections/*-v40.html`), the React kits (`ui_kits/neon-terminal-v4/*.jsx`), the token drop-in (`colors_and_type.css`), and the `DESIGN_SYSTEM.md` / `README.md` direction notes.

## TL;DR — biggest shifts

- **Terminal-window hero** — the centred hero stack is wrapped in a macOS-style terminal panel (traffic-light dots, `tom@matrix ~` path, glass blur) and gains real **View Projects / Get in Touch** CTAs the live site lacks.
- **System Status dashboard (net-new)** — a `system_status ● online` eyebrow, 4 stat tiles, `core_skills` bars, a `recent_activity` feed and a `now` panel are added below the hero; v3.5 renders nothing in this slot.
- **ShadCN segmented tabs + lifted glass cards** — the Orbitron filter chips + 3D-flip + paginated project grid become a segmented `(count)` tab bar over static, pre-lifted glass cards with category left-border colour coding and a bottom glow puck.
- **OKLCH four-theme token system** — hex/rgba Matrix colours are recast as OKLCH ShadCN tokens; dark-blue theme retired, new `neon-terminal` (dark) + `circuit` (light) themes added; toggle flips dark↔light.
- **Framer-Motion-only consolidation** — five animation libraries (anime.js, AOS, GSAP, ScrollMagic, Framer Motion) collapse to Framer Motion alone; 30+ CSS partials (~38k lines) collapse to a single `app.css` + Tailwind v4 + ShadCN.
- **Lucide icons replace Font Awesome** — chrome, cards and page bodies move from FA `<i>` glyphs to inline Lucide SVGs (GitHub/LinkedIn kept as custom brand SVGs); the FA CDN link is dropped.
- **Magnetic nav indicator** — the static underline-grow active state becomes a sliding indicator that follows hover and snaps back to the active route, plus a contained pill nav, status pill, ⌘K search and a UTC clock.
- **Sentence-case terminal voice** — forced-UPPERCASE Orbitron headings give way to sentence-case headings with lowercase `snake_case` mono eyebrows (`about`, `tech_stack`, `featured`, `all_projects`); the `$ cat about.md` motif reframes copy.
- **Brand-voice content rules (not just styling)** — first-person casual British English (specialise / behaviour / optimise / colour, never Americanised), no marketing fluff (no synergy / leverage / unlock), rule-of-three sentence rhythm, terminal prefixes as real copy, **no emoji ever**, and the Matrix origin story kept verbatim. See §7.

## 7. Voice & content fundamentals (copy rules, not styling)

The handoff treats brand voice as documented scope in its own right ("the brand voice IS the brand", `README.md:390-401`), separate from the visual sentence-case / `snake_case` / `$ cat about.md` *styling* covered in §1–§6. These are content rules that constrain the actual words shipped, so they belong in the diff as enforceable copy conventions rather than as typography. Most have no live counterpart to migrate — they are net-new editorial guardrails for v4.0 copy (and for any AI-generated copy during the build).
